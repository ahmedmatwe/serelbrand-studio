# Music bed (optional)

Put royalty-free tracks you are licensed to use on YouTube here (mp3/m4a/wav).
Best source: **YouTube Studio → Audio Library** (free, safe from Content ID claims).
Name files with a mood word so the system can choose: `suspense-*.mp3`, `inspiring-*.mp3`, `calm-*.mp3`.
The music is auto-ducked under the narration. Without tracks, videos get voice + sound effects only.
